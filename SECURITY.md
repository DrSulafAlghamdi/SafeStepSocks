# Security policy

This is a prototype. It has **no supported medical, connected-device or alerting deployment**.

Do not use it as an emergency notification system. Do not connect to production patient records or publish raw participant telemetry. Report security concerns privately to the repository owner through an appropriate contact channel once configured; do not post sensitive examples in public issues.

Before production, conduct threat modeling for pairing, BLE transport, mobile authentication, encryption, role-based caregiver access, update authenticity, offline behavior, and alert-delivery assurance.
