# Contributing

SafeStepSocks is an early-stage research project. Discuss proposed contributions with the project owner before sharing proprietary ideas or data.

- Keep sensor samples **de-identified**; never commit participant names, contact details, medical records, or exact locations.
- Include an explanation and unit tests when changing detector logic.
- Report sensitivity, missed falls, false positives and evaluation denominator; do not report a single 'accuracy' figure without context.
- Separate simulated data, human-subject results and clinical evidence.
- Do not merge claims about medical performance or commercial partnerships without supporting documentation.
- See [docs/publication-ip.md](docs/publication-ip.md) before publishing design details.
