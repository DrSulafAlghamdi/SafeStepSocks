# Roadmap (proposed milestones; not committed delivery dates)

## Stage 1 — Proof of concept

- [x] Reproducible Python experimental detector
- [x] Synthetic data generator and automated unit tests
- [x] Reference ESP32/MPU6050 USB firmware
- [ ] Bench-build and record versioned hardware tests
- [ ] Document prototype photos, size, textile specifications and component costs

## Stage 2 — Validation

- [ ] Establish an ethics/safety-appropriate evaluation protocol
- [ ] Define fall and false-alarm ground-truth criteria
- [ ] Collect independent, consented and de-identified trials
- [ ] Report sensitivity, specificity, false alerts/hour, latency and confidence intervals
- [ ] Evaluate textile traction, comfort, compression pressure and wash durability

## Stage 3 — Product engineering

- [ ] Design safe removable electronics enclosure and power system
- [ ] Add tested wireless connectivity and caregiver acknowledgments
- [ ] Threat-model and implement secure device/app pairing
- [ ] Revise signal-processing approach for foot-worn motion and diverse users

## Stage 4 — Institutional pilot and commercialization

- [ ] Obtain written clinical feedback / letter(s) of interest
- [ ] Assess SFDA classification and other applicable regulatory requirements
- [ ] Conduct appropriately governed pilot studies
- [ ] Confirm manufacturing partner, unit economics, quality processes and maintenance
- [ ] Make explicit decision about IP and public release
